# LunarAI — UI/UX Design System

**Deep Space Professional · mission-console interface for the LunarAI multi-modal lunar image correspondence & registration platform (ISRO · SIH 2026 · PS26166).**

This document is the reference for the shipped interface — every token, component, layout rule and page described here exists in code under `app/lib/`. The implementation is a fully re-skinned Streamlit application (no React toolchain): the shell is generated by `app_build.py` → `app/streamlit_app.py`, the design system lives in `app/lib/design.py` + `app/lib/theme.py`, the component library in `app/lib/components.py` / `charts.py` / `figures.py`, and the nine page modules in `app/lib/pages/`.

---

## 1. Design principles

| # | Principle | How the code enforces it |
|---|---|---|
| 1 | **Evidence, not decoration** — every number on screen is read from a generated artifact at render time | `lunarai_lib/appdata.py` fault-tolerant readers; tests assert headline metrics match the real CSV/JSON/DB |
| 2 | **Mission-critical calm** — dark, low-chroma surfaces; colour reserved for meaning (status, sensors, deltas) | 90 % of the UI is `#020617`–`#111827`; accent/success/warning/error appear only in badges, thresholds and series colours |
| 3 | **Honesty as a feature** — limitations, caveats and negative results are first-class UI | SIFT benchmark warning, ECC demo-pair quarantine expander, confidence-as-blend caption, synthetic-illumination labelling |
| 4 | **Zero default chrome** — nothing on screen should say "Streamlit" | header/footer/deploy button/toolbar removed via CSS; all controls re-skinned; `st.dataframe` is themed and never used for small tables |
| 5 | **Role-aware density** — the same platform serves scientists, judges and engineers without mode-switching cost | "View as" role selector presets destination + judge mode; judge mode hides technical controls in one click |

Reference visual language: NASA PDS / ISRO mission operations / ESA EO dashboard / Palantir Foundry / SpaceX mission control.

Translucent tints (`TINTS`) generate chips/badges/glows; `GRADIENTS` defines `aurora` (accent→violet), `panel`, `hero`, `glow`. `SENSOR_COLORS` fixes the mission legend: **OHRC** `#38BDF8` · **TMC-2** `#7C3AED` · **IIRS** `#22C55E` · **LRO NAC** `#F59E0B` · **KAGUYA** `#06B6D4`.

Everything surfaces as CSS custom properties (`--lai-*`) from `theme.py`; components never hard-code hex values.

### 2.2 Typography

| Role | Stack | Notes |
|---|---|---|
| Display (hero, h1–h5, section titles) | `Poppins → Inter → SF Pro Display` | 600–700, −0.015 em tracking, `!important` guard beats Streamlit's own heading rules |
| Body / UI | `Inter → SF Pro Display` | 0.95 rem, `#94A3B8` |
| Data / mono | `JetBrains Mono → Consolas` | metric values, table cells, code, coordinates |

Scale: hero `2.6rem` → h1 `2rem` → h2 `1.4rem` → h3 `1.1rem` → body `0.95rem` → small `0.82rem` → micro `0.7rem`; metric values `1.85rem` (`metric_sm` 1.25). Webfonts load from Google Fonts with `display=swap`; the stacks degrade cleanly if offline.

### 2.3 Space, radius, elevation, motion

- **Space**: 2 / 4 / 8 / 12 / 16 / 24 / 32 / 48 px.
- **Radius**: 8 (sm) / 12 (md) / 16 (lg) / 22 (xl) / pill.
- **Shadows**: `sm` hairline lift · `md` card · `lg` modal/hero · `glow` accent ring (`0 0 0 1px rgba(56,189,248,.35), 0 8px 40px rgba(56,189,248,.18)`).
- **Motion**: fast `0.16s` / base `0.28s` / slow `0.6s`, all `cubic-bezier(0.4,0,0.2,1)` or `(0.16,1,0.3,1)`; hover transforms, animated flow pulse, KPI value transitions.
- **Layout**: sidebar `272px`, content max-width `1680px`, top bar height `64px`.

### 2.4 Quality thresholds (honest, centralised)

`THRESHOLDS` + `status()` classify every metric — RMSE (lower-is-better: ≤0.5 excellent / ≤1.0 good / ≤2.0 acceptable), coverage (≥0.8 / 0.6 / 0.4), confidence, inlier ratio — and `status_color()` / `status_label()` map classes to colours and `EXCELLENT / GOOD / ACCEPTABLE / REVIEW / NO DATA` wording. `charts` and `components.status_badge` consume these, so no page invents its own verdict.

### 2.5 Chart theme

`design.plotly_layout()` is applied to **every** Plotly figure: transparent plot/paper, `#94A3B8` 12 px Inter ticks, hairline grid, mono-font hover labels, horizontal legend below, colourway `[accent, violet, success, warning, teal, error]`. Result: charts read as instrument panels, not Plotly defaults.

## 3. Information architecture

### 3.1 The nine destinations (`app/lib/pages/__init__.py`)

`PageSpec(key, icon, label, render, group)` — the registry is the single source of truth; `NAV` derives the sidebar labels; the generator (`app_build.py`) and the generated shell (`app/streamlit_app.py`) are test-asserted to stay identical.

| Group | Key | Sidebar entry | Purpose |
|---|---|---|---|
| Overview | `dashboard` | 🌕 Mission Dashboard | Hero, live KPIs, pipeline, coverage, evidence links |
| Data | `dataset` | 📤 Dataset Manager | Upload, inventory, health, coverage, storage |
| Analysis | `retrieval` | 🧠 LunaDNA Retrieval | Live query → Top-K, embedding map, retrieval quality |
| Analysis | `registration` | 📍 Image Registration | Live pair runs, 4-mode viewer, matrices, validation |
| Evidence | `analytics` | 📊 Validation Analytics | 6 tabs over every validation campaign |
| Evidence | `reports` | 📑 Reports & Exports | Deliverables, CSV tables, figures, session log |

## 4. Application shell

### 4.1 Top mission header (`.lai-topbar`, components.topbar)

Sticky, blurred `#0F172A→#020617` bar: **brand** (gradient lunar disc + "LunarAI" + "ISRO · PS26166") · **status readouts** (label+value pairs: MISSION / DATASET / MODEL / EXPERIMENT / ROLE) · **controls** (judge-mode toggle, theme toggle, role selector, notification centre). Under it, the shell renders the judge/theme/role/notification controls; the notification centre aggregates honest advisories (AKAZE absent, KAGUYA tile truncation, missing robustness evidence, live checkpoint epoch).

### 4.2 Sidebar (272 px, collapsible)

Brand block → "Navigate" label → the nine entries as a re-skinned radio list (active = accent gradient + 3 px left rule + glow; hover slide) → **layer footer** (current group + page) → **session footer** (device, matcher, FAISS vectors, images, patches, version). Collapse is Streamlit-native; the re-open control is re-homed by the theme to a fixed 36 px square button (top-left, always clickable — see §9).

### 4.3 Session state contract

`nav`, `judge_mode`, `theme`, `role` live in `st.session_state`; the shell is the only writer (pages never mutate nav — test-enforced). `nav_request` lets any page's quick-link buttons change destination before the next render. Roles: **ISRO Scientist** → Dashboard, **Planetary Researcher** → Retrieval, **Remote Sensing Expert** → Registration, **SIH Judge** → Dashboard + judge mode, **AI Engineer** → System Health.

## 5. UX flows (per user type)

**ISRO Scientist** — land on Dashboard → scan KPI grid + coverage disc → jump to Registration via quick-link → run a live pair → inspect matrix + sub-pixel evidence → export the session CSV from Reports.

**Planetary Researcher** — role selector drops them on Retrieval → query panel (uploaded image or catalogued patch) → Top-K cards with similarity badges → ranking/similarity charts + PCA embedding map → cross-check validated recall tables → explore patches in the gallery.

**Remote Sensing Expert** — Registration page: configure a live run → reference/query/result quadrants → switch viewer modes (side-by-side / overlay / difference / swipe) → toggle match layers (all / inliers / outliers) → expand transformation matrix, matching statistics, geometric validation.

**SIH Judge** — "View as SIH Judge" (or the 🏆 button) → technical controls disappear, sidebar becomes a presentation panel → 10 numbered steps tell the story (Problem → Solution → Pipeline → Results → Benchmarks → Innovation → Live demo → Impact → Robustness → Future scope) → exit restores the console exactly as it was.

**AI Engineer** — Health page: live psutil telemetry (CPU/RAM/disk/threads), model + FAISS index sizes, one-pass embedding probe, storage chart, readiness JSON → About for the exact stack versions.

### 6.4 Micro-interactions

Hover elevation + accent borders on cards/nav/KPIs; animated KPI values; skeleton loaders; progress meters; tooltips on every KPI footnote; success toasts after live runs; Plotly hover crosshairs in mono type; 0.16–0.28 s transitions throughout.

## 9. Professional CSS theme — mechanics

`theme.css()` composes: `:root` token block → reset + app background → **chrome removal** (header collapsed to 0-height/transparent but *not* `display:none`, toolbar/decoration/status widget/MainMenu/footer/deploy button removed) → typography (Poppins `!important` on h1–h5, JetBrains Mono on metric values) → sidebar skinning → buttons/tabs/selects/expanders/popovers/metrics → `.lai-*` component classes → dataframe theming → responsive + print → light-theme override block (`light_override()`, applied by the shell on toggle).

Streamlit also paints `st.dataframe` interiors on a `<canvas>`, which CSS cannot reach; `.streamlit/config.toml` pins the base theme (`base="dark"`, background `#020617`, secondary `#111827`, primary `#38BDF8`, text `#F8FAFC`) so even canvas pixels match the palette.

**Frontend structure note:** the brief lists ECharts/D3/Three.js as *options*; the shipped system standardises on **Plotly (15+ chart types) + hand-built SVG instruments**, which cover every required visual with zero additional runtime dependencies — a deliberate scope decision, documented here.

## 10. Honest-metrics guardrails (UI-enforced)

- **SIFT honesty**: Analytics Benchmark tab prints the warning that SIFT leads single-pair recall (0.88 vs 0.68) while LunarAI leads inlier ratio @3 px and is the only system that localizes.
- **ECC demo-pair quarantine**: the 27-row `ecc_report.csv` is synthetic `feat_*` pairs; every ECC-derived accuracy claim carries a caveat expander and the headline RMSE uses the 29-pair `subpixel_accuracy_report.csv` (median 0.2556 px, 86.2 % < 1 px).
- **Confidence is a blend, not a probability**: 25 % similarity + 30 % inliers@3px + 30 % RMSE + 15 % coverage — stated on every page that shows it.
- **Synthetic sun bins are labelled**, 4×/8× scale points report `insufficient_matches` instead of being faked, KAGUYA claims retrieval-driven localization only, catalogue coordinates carry ±0.25° uncertainty.
